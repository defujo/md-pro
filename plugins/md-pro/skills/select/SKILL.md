1. Покажи пользователю этот вывод как есть, без первой строки «Вывод программы плагина md-pro:».
2. Если в выводе есть нумерованный список мдшек, добавь одну строку: «Чтобы выбрать, введите /md-pro:select и md_id мдшки, например: /md-pro:select 3» — подставь md_id из списка.

Если такого вывода в контексте нет, ответь: «Плагин md-pro не ответил на команду. Обновите Claude Code (`claude update`) и начните новую сессию».
