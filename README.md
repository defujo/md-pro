# md-pro для Claude Code

Плагин загружает правила проекта (мдшку) под вашу модель Claude в начале каждой сессии. Для работы нужен ключ доступа.

## Установка (4 шага)

1. Обновите Claude Code — в терминале: `claude update`.
2. Внутри Claude Code выполните:
   ```
   /plugin marketplace add defujo/md-pro
   /plugin install md-pro@md-pro
   ```
   При установке выберите **«Install for you (user scope)»** — тогда правила работают во всех ваших проектах.
3. Claude Code попросит **ключ** — вставьте ключ, который вам выдали.
4. Включите автообновление плагина: `/plugin` → Marketplaces → md-pro → Enable auto-update.

Перезапустите Claude Code. В начале сессии появится строка вида
`✓ Opus 5.5 · «Основная» · версия 3 · подписка до 30.10`.

## Команды

- `/md-pro:status` — ключ, подписка, этот компьютер, какие правила загружены.
- `/md-pro:select` — список вариантов правил для вашей модели; `/md-pro:select <номер>` — выбрать.

## Важно

- Ключ работает на **одном компьютере**. Для смены компьютера напишите владельцу.
- Сменить ключ: `/plugin` → Installed → md-pro → Configure options.
- Нужен установленный git. Работает в локальном Claude Code (терминал, VS Code, JetBrains, приложение);
  в claude.ai/code и облачных сессиях плагины не загружаются.
- На сервер отправляются: ключ, модель, хэш отпечатка компьютера, номер сессии и части, версия плагина.
  Код и файлы ваших проектов никуда не отправляются.
